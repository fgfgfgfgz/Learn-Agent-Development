## 开头一句话

昨天你用 `while` + 索引写了待办清单的「查看清单」功能：

```python
i = 0
while i < len(todo):
    print(todo[i])
    i = i + 1
```

四行里有三行在做同一件事——**数数**：`i` 从 0 开始、检查是否越界、取出来、再加 1。真正想说的只有中间那句 `print(todo[i])`。

今天学的 `for` 就是把这三行数数全包办了：**「列表里每个元素，挨个给我」**。这是 Python 最优雅的地方之一，你以后写的代码里 `for` 会比 `while` 多得多。

## 今日知识点（25 分钟）

### 1. for 的基本形状（7 分钟）

```python
todo = ["装 Python", "学 if", "学 while"]

for t in todo:
    print(t)
```

输出：

```
装 Python
学 if
学 while
```

三件事：

| 要素 | 例子 | 说明 |
| --- | --- | --- |
| `for` + 变量 | `for t in todo:` | `t` 每次自动指向一个元素，**不用你赋值** |
| `in` 后面跟**可遍历的东西** | `todo` | 列表、字符串、`range()` 都行 |
| 冒号 + 缩进 | `print(t)` 缩进 4 格 | 和 `if`/`while` 一样，缩进的行才重复执行 |

**对比昨天**：`while` 版你要自己管 `i`、`len()`、`i = i + 1`；`for` 版这些全没了。`t` 这个名字随便起（写 `for item in todo:` 也行），但习惯用有意义的名——遍历待办就叫 `task`，遍历字符就叫 `ch`。

### 2. 三种常见的遍历对象（6 分钟）

**遍历列表**（上面已做）。

**遍历字符串**——字符串也是"一串字符"，可以挨个取：

```python
for ch in "AI":
    print(ch)
# A
# I
```

**遍历 `range()`**——当你只是想"重复 n 次"，或者需要序号时。这是今天第一个正式认识的新函数，按五要素讲透（以后每个新函数都这样讲）：

> ### 🔧 函数卡片：`range()`
>
> **① 它是什么**：Python 内置的一个"数字序列生成器"。你给它起点、终点、步长，它按规则造出一串整数给你挨个用。它本身不是列表，是一份"生产数字的配方"。
>
> **② 参数**（三种写法，参数个数不同）：
>
> | 写法 | 参数 | 说明 |
> | --- | --- | --- |
> | `range(stop)` | `stop`：**必填** | 从 0 数到 `stop-1`，**不含 stop** |
> | `range(start, stop)` | `start` 必填、`stop` 必填 | 从 `start` 数到 `stop-1`，**不含 stop** |
> | `range(start, stop, step)` | 三个都必填 | `step` 是步长（每隔几个取一个），默认不写时是 1 |
>
> - `start` 不写时**默认是 0**；`step` 不写时**默认是 1**。
> - 三个参数都是**整数**；`step` 可以是负数（倒着数，今天不用管）。
>
> **③ 返回值**：返回一个 **`range` 对象**（一种序列），**不是列表**。直接 `print(range(3))` 会显示 `range(0, 3)` 而不是 `0 1 2`——想看见里面的数字，要用 `list()` 转换：`list(range(3))` → `[0, 1, 2]`。但 `for i in range(3):` 不需要转换，for 能直接挨个取。
>
> **④ 最小例子**：
> ```python
> for i in range(3):
>     print(i)
> # 0
> # 1
> # 2
> ```
>
> **补充：print 到底显示什么？**（这条通用规则以前没系统讲过，今天补上）
>
> 你之前 print 的都是**变量**：`print(todo)` 显示列表的值、`print(name)` 显示字符串内容。
> 这次 `print(range(3))` 不一样——你打印的是一个**函数直接返回的对象**，中间没经过变量。
> 规则很简单：**每种对象都有自己的"自我介绍"，print 就照着这个长相显示**：
>
> | 你 print 的东西 | 屏幕显示 |
> | --- | --- |
> | 字符串 | 内容本身，不带引号：`装 Python` |
> | 列表 | 带中括号：`['装 Python', '学 if']` |
> | range 对象 | `range(0, 3)` |
> | 数字 | 数字本身：`42` |
>
> 所以 `print(range(3))` 显示 `range(0, 3)` 是顺理成章的——那就是 range 对象的"长相"。
> 想看 range 里具体有哪些数字，用 `list()` 转成列表再 print（见上面的例子）。

> **⑤ 常见坑**：**终点永远不含**。`range(3)` 是 `0 1 2`（3 个数，但没有 3）；`range(1, 4)` 是 `1 2 3`（没有 4）。想让序号从 1 数到 5，写 `range(1, 6)`，不是 `range(1, 5)`。这就是你 11-17 第 2 题 `<` 不含边界的同一个道理。

### 3. for 和 while 怎么选（4 分钟）

一句话判断：

- **已知要遍历一个东西**（列表、字符串、固定次数）→ 用 `for`
- **不知道要重复几次，等某个条件变化才停** → 用 `while`

你的待办清单就是典型例子：菜单循环「反复等用户选择，直到他选退出」——次数事先不知道 → 外层继续用 `while True`；而「查看清单」是把列表里每一项打印出来——已知遍历列表 → 内层改成 `for`。

两种循环不冲突，经常配着用：外层 `while` 管流程，内层 `for` 管遍历。

### 4. break / continue 在 for 里一样用（4 分钟）

昨天学的两个「提前撤退」指令，`for` 里完全通用：

```python
for n in range(1, 6):
    if n == 2:
        continue     # 跳过 2
    if n == 4:
        break        # 跳出整个循环
    print(n)
# 1
# 3
```

输出 `1 3`——和昨天的 `while` 版一模一样。你昨天已经亲手验证过 break 时「最后一位打印不出来」，这里只是换个循环写法，**规则不变**。

### 5. 需要序号时怎么办（4 分钟）

`for t in todo` 直接给你元素，但没有序号。昨天的清单要显示「1. 装 Python」这种带编号的，怎么办？最简单的写法——**自己维护一个计数器**：

```python
todo = ["装 Python", "学变量", "学 if"]
i = 1
for t in todo:
    print(f"{i}. {t}")
    i = i + 1
```

输出：

```
1. 装 Python
2. 学变量
3. 学 if
```

这比 `while` + 索引少操心多了：不用管 `len()`、不用管越界，只管「数到几」。

> 你会看到别人写 `for i, t in enumerate(todo):` 一步到位——今天**不讲**，先用上面的笨办法。等你写顺了，那个只是个语法糖，一眼就懂。

## 动手练习（15 分钟）

产出：`练习/20261118/todo_cli_for.py`

把昨天 `练习/20261117/todo_cli.py` 的「查看清单」那一段从 while 改成 for。完整代码（对照着看改了哪里）：

```python
todo = ["装 Python", "学变量", "学 if"]

while True:
    print("\n===== 待办清单 =====")
    print("1. 查看清单")
    print("2. 添加任务")
    print("3. 检查某项")
    print("4. 退出")

    choice = input("请选择 1-4：")

    if choice == "1":
        # ===== 只有这里从 while 改成了 for =====
        i = 1
        for t in todo:
            print(f"{i}. {t}")
            i = i + 1
    elif choice == "2":
        new = input("输入新任务：")
        todo.append(new)
        print(f"已添加「{new}」")
    elif choice == "3":
        target = input("要检查哪项：")
        if target in todo:
            print(f"「{target}」在清单里")
        else:
            print(f"「{target}」不在清单里")
    elif choice == "4":
        print("再见！")
        break
    else:
        print("输入有误，请输入 1-4")
```

**跑起来做两件事**：

1. 选 1 查看清单——输出和昨天**一模一样**（`1. 装 Python` / `2. 学变量` / `3. 学 if`），但代码从 4 行变 3 行、还不用操心 `len()` 和越界。
2. 选 2 添加「学 for」→ 再选 1——确认新任务自动出现在第 4 行（`for` 遍历的是"当前"的列表）。

**再想一下**（不用写）：如果清单是空的 `[]`，`for t in todo` 会执行几次？答案是 0 次——循环体一次都不跑，正好对应昨天 `if not todo` 那个分支。

> 求职相关：`todo_cli.py` 和这个 for 版，两个都留着。面试时被问「while 和 for 有什么区别」，你不用背定义，直接说「我当时写待办清单，外层菜单次数不定用 while，内层遍历列表用 for，因为 for 不用我管索引和越界」——这就是 best answer。
