## 今日知识点（30 分钟）

### 1. 程序是什么，Python 又是什么（4 分钟）

- **程序 = 一份照着做的菜谱**：一行一行写清楚「先做什么、再做什么」，电脑严格按顺序执行，不会自己猜你的意思。
- **Python 是一种写菜谱的语言**。它接近英文、不用管很多底层细节，所以写得快。
- **为什么 AI Agent 开发几乎都用 Python**：调用大模型、处理文档、接数据库、主流 Agent 框架（LangGraph 等）全都有现成的 Python 工具包。你不是要成为语言专家，而是要用它把各个部件串起来。
- 一个关键心态：**代码写错是常态，不是你笨**。专业开发者一天也要看几十次报错。

### 2. 安装 Python（10 分钟，Windows 具体步骤）

1. 浏览器打开 `https://www.python.org/downloads/`，点黄色按钮下载 Windows 安装包（Python 3.12 或 3.13 均可，选 64-bit）。
2. 双击安装包。**最关键的一步：窗口最底部有个复选框 `Add python.exe to PATH`，务必先勾上**，再点 `Install Now`。
   - 这个勾的作用是：让电脑在任意位置都认识 `python` 这个命令。不勾，后面 90% 的「装了却用不了」都来自这里。
3. 出现 `Setup was successful` 后，按 `Win + R`，输入 `cmd`，回车，打开黑色终端窗口。
4. 输入 `python --version` 然后回车。看到类似 `Python 3.13.1` 就成功了。
5. 如果提示 **「'python' 不是内部或外部命令」**：重新双击安装包 → 选 `Modify` → 补上 PATH → 完成；或直接卸载重装并记得勾选。也可以用 `py --version` 先确认 Python 本体确实装上了。

```
C:\Users\你> python --version
Python 3.13.1
```

> 常见坑：装完 Python 但**忘记重开终端**。已经开着的窗口不认识新命令，关掉重开一次即可。

### 3. 装写代码的地方：VS Code（6 分钟）

1. 打开 `https://code.visualstudio.com/`，下载并安装（一路下一步即可）。
2. 打开 VS Code，按 `Ctrl + Shift + X` 打开扩展面板，搜 `Python`，安装 **Microsoft 官方**那个（下载量最大的）。
3. 用菜单 `文件 → 打开文件夹`，打开已经建好的 `E:\ai_create\学习计划\练习\20261111`。
4. 按 `Ctrl + \``（数字 1 左边那个键）或菜单 `终端 → 新建终端`，打开下方终端。
   - **用「打开文件夹」的方式进入，终端会自动定位到该目录**，你不用手动输入含中文的路径，省掉一堆麻烦。

到这里你有了：一个写代码的编辑器 + 一个能运行的终端。

### 4. 第一行代码：`print()`（7 分钟）

在左侧文件列表新建 `hello.py`，输入这一行并保存：

```python
print("Hello, Agent!")
```

在下方终端输入 `python hello.py` 回车，屏幕上会出现 `Hello, Agent!`。

把这一行拆开看，只有四样东西：

| 部件 | 名字 | 作用 |
| --- | --- | --- |
| `print` | 函数名 | 「把东西显示到屏幕上」这个动作。函数 = 一个已经做好的功能，你喊它的名字就能用 |
| `( )` | 圆括号 | 把要处理的内容交给这个函数。括号里是「参数」 |
| `"..."` | 引号 | 表示里面是**字符串**（一段文字），不是命令。引号必须成对 |
| `#` | 注释符号 | 这一行 `#` 后面的内容电脑**完全忽略**，是写给人看的备注 |

再试两行，感受一下：

```python
print(2026)          # 打印数字，数字不用加引号
# 下面这行不会被执行
print("我在第 1 天")
```

> 常见坑：引号、括号用了中文全角 `“ ”` `（ ）` 会直接报错。**写代码时输入法切到英文半角**。这是零基础第一天的头号错误。

### 5. 看懂报错（3 分钟）

故意把代码改成 `print(Hello, Agent!")`（删掉第一个引号），保存后运行，会看到一片红色文字。别慌，只看最后一行，例如：

```
SyntaxError: unterminated string literal
```

- `SyntaxError` = 语法写错了（就像句子少了个标点）。
- 报错里通常还有 `line 1`，告诉你错在第 1 行。
- **报错是电脑在帮你定位问题，不是评判你**。把引号补回去、保存、再运行，红色就消失了。

> 若终端里中文显示成乱码：这是 Windows 终端编码问题，今天**先不管**，只要看到了输出就算成功，下次会顺手处理。

### 第 1 题 · 25 分 · 得 0 分

**题目**：关于电脑怎么执行你写的代码，下面哪个说法是对的？

- A. 严格按这一行指令，把引号里的文字显示到屏幕上
- B. 会先理解你的意图，再决定显示什么
- C. 引号里的文字会被当成一条命令执行
- D. 必须先装好编辑器扩展，才会执行这行代码

**你的回答**：D

**正确答案**：A

**评语**：错在把「装扩展」当成了代码能跑的前提，混淆了**编辑工具**与**运行环境**。VS Code 和它的 Python 扩展只负责高亮、补全、报错提示，是写字的地方；真正执行代码的是 Python 解释器（也就是你在终端里敲的 `python`）。用记事本写一行代码，照样能在终端跑起来。
