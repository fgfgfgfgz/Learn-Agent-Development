## 回顾与补漏（20 分钟）

### 上次唯一真错：不是「谁帮你写字」，而是「谁真的执行」

先把上次第 1 题讲的那些错误答案放一边，用一句话定住：

> **VS Code 是写字的地方，Python 解释器是执行的地方。**

- **编辑工具**（VS Code、记事本、PyCharm）：只负责让你把文字打进去、看着舒服（高亮、补全、提示）。它**不会**执行你的代码。
- **运行环境**（Python 解释器，也就是终端里的 `python`）：真正读懂你的代码、一行行执行、把结果打出来。
- **扩展**（VS Code 的 Python 扩展）：只是给编辑工具加功能的插件，负责语法高亮、代码补全、点绿三角运行——但它自己**不带** Python，也不负责执行。它只是替你**去调用**解释器。

打个比方：VS Code 是**厨房台面**，Python 解释器是**灶**。台面再好，没有灶也做不出饭；而扩展是台面上的**置物架**，让东西好拿，但它不产火。

## 今日知识点（20 分钟，只讲一个点）

### 变量：给数据起个名字

**是什么**：变量就是一个**贴了名字的盒子**，你把数据放进去，之后用名字就能取出来用。

```python
name = "小明"
print(name)
```

运行结果：

```
小明
```

拆开看这一行 `name = "小明"`：

| 部件 | 名字 | 作用 |
| --- | --- | --- |
| `name` | 变量名 | 你给这个盒子起的名字，之后用它取数据 |
| `=` | 赋值符号 | **不是数学里的「等于」**，而是「把右边的东西装进左边的盒子」 |
| `"小明"` | 值 | 装进去的内容（这里是字符串） |

**为什么要用它**：如果不用变量，同一个数据你每处都要重写一遍，改的时候容易漏。用了变量，写一次、到处引用，改也只改一处。

```python
city = "杭州"
print("我住在" + city)
print(city + "今天天气不错")
```

```
我住在杭州
杭州今天天气不错
```

**三条必须记住的规则**：

1. **变量名不用加引号**。`name = "小明"` 对；`"name" = "小明"` 错。加了引号它就变成一段文字，不再是名字。
2. **`=` 是「装进去」，`==` 才是「比较是否相等」**。这两个明天以后会反复用到，现在先记住它们不是一回事。
3. **变量的值可以改，后写的覆盖先写的**：

```python
score = 60
print(score)     # 60
score = 62
print(score)     # 62，旧值被覆盖了
```

**常见坑**：

- 变量名**区分大小写**：`Name` 和 `name` 是两个不同的盒子。
- 变量名不能有空格、不能以数字开头。用下划线连接最稳妥：`my_score`。
- 用了没定义的变量会报 `NameError`（名字未定义）——意思是「这个盒子里还没装东西，我不认识它」。
- 变量**只活在本次运行里**。程序结束，盒子就清空了，下次运行重新开始。

> 顺便回应上次的报错类型：`SyntaxError` 是「句子写错了」，`NameError` 是「这个名字我不认识」。两者都是报错，但原因完全不同。

**为什么现在学变量**：后面调用大模型时，你的 API 密钥、用户的问题、模型的回答，全都要装进变量里传来传去。这是接下来所有代码的地基。

## 答疑记录（学习中提出的问题）

### 为什么 name、city 不加 `str()`，days 要加？print 不能直接打印数字吗？

**先纠正前提**：print **能**直接打印数字，从来不挑类型。

```python
print(2026)      # 2026
print("abc")     # abc
print(days)      # 2      ← days 是数字，照样打
```

**真正报错的是 `+`，不是 print。** 区别在这三行括号里的内容：

| 代码 | 类型情况 | 结果 |
| --- | --- | --- |
| `name + " 正在学习 Python"` | 文字 + 文字 | 拼接，正常 |
| `"我在 " + city` | 文字 + 文字 | 拼接，正常 |
| `"今天是我学习的第 " + days` | 文字 + **数字** | `TypeError` |

`name` 和 `city` 装的是字符串 `"小明"`，和相邻文字同类；`days` 装的是整数 `2`，类型对不上。

报错原文：

```
TypeError: can only concatenate str (not "int") to str
```

意思是「加号只能拼接字符串，你给了一个 int」。

**`+` 的规则：两边类型必须一致。**

| 表达式 | 结果 | 说明 |
| --- | --- | --- |
| `"小明" + "在杭州"` | `小明在杭州` | 文字＋文字 = 拼接 |
| `2 + 3` | `5` | 数字＋数字 = 加法 |
| `"第 " + 2` | **TypeError** | 文字＋数字 = 不匹配 |

同一个 `+`，两边是文字就拼接、是数字就相加，**混着来就报错**——Python 不会替你猜你是想拼接还是想加法。

**`str()` 的作用**：把值转成文字。`str(2)` 得到 `"2"`（带引号的文字，不是数字）。
于是 `"第 " + str(days) + " 天"` 变成 `"文字" + "2" + "文字"`，三边全是文字，加号才能一路拼下去。

**另外两种写法**（现在只需认识，后面会正式讲）：

```python
print("今天是我学习的第", days, "天")   # 逗号分隔，print 自动用空格连接
print(f"今天是我学习的第 {days} 天")     # f-string，最常用，推荐
```

一句话记住：**加号要求类型一致，这是加号的限制，不是 print 的限制。**
