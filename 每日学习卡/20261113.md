## 今日知识点（30 分钟）

### 1. 四种基本类型（8 分钟）

Python 里最常用的四种数据，先认脸：

| 类型 | 名字 | 写法 | 例子 |
| --- | --- | --- | --- |
| `int` | 整数 | 不加引号 | `2026`、`-5`、`0` |
| `float` | 小数（浮点数） | 带小数点 | `3.14`、`0.5`、`-2.0` |
| `str` | 字符串（文字） | **加引号** | `"你好"`、`"2026"`、`"3.14"` |
| `bool` | 布尔（真假） | 只有两个值 | `True`、`False` |

**关键分辨点，也是新手最容易懵的地方**：

```python
2026      # int，数字
"2026"    # str，文字！长得像数字，但它是文字
```

**加了引号就是文字，加了引号就是文字，加了引号就是文字。** 这两个东西在 Python 眼里完全是两种物种——`2026` 能参与算术，`"2026"` 只能当文字拼接。上一课那个 `TypeError` 就是这么来的。

`bool` 只有两个值：`True` 和 `False`（**首字母大写，不能写成 `true`**）。它看着简单，但后面所有判断（如果…就…）都建立在它上面。

### 2. 用 type() 查类型（4 分钟）

不用猜，让 Python 自己告诉你：

```python
print(type(2026))
print(type(3.14))
print(type("2026"))
print(type(True))
```

输出：

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

`<class 'xxx'>` 里的 `xxx` 就是类型名。**遇到「为什么这行报错」时，第一反应就该是 `print(type(那个东西))`** ——这是排查类型问题最快的手段，比猜快得多。

### 3. 算术运算符（8 分钟）

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | `9` |
| `-` | 减 | `7 - 2` | `5` |
| `*` | 乘 | `7 * 2` | `14` |
| `/` | 除 | `7 / 2` | `3.5` |
| `//` | 整除（只留整数部分） | `7 // 2` | `3` |
| `%` | 取余（除完剩多少） | `7 % 2` | `1` |
| `**` | 乘方 | `7 ** 2` | `49` |

**三个必须留意的点**：

1. **`/` 的结果永远是小数**。`4 / 2` 得到 `2.0` 而不是 `2`——类型是 `float`，不是 `int`。这是很多人第一次踩的坑。
2. **`//` 是整除，直接砍掉小数部分**。`7 // 2` 是 `3`，不是 `3.5`，也不四舍五入。
3. **`%` 是取余数**，不是百分号。`7 % 2` 得 `1`（7 除以 2 商 3 余 1）。它最常用的场景是判断「能不能被整除」：`n % 2 == 0` 就是偶数。

`+` 在上一课已经见过它的两种身份：

```python
print(3 + 4)          # 7      数字 + 数字 = 加法
print("3" + "4")      # 34     文字 + 文字 = 拼接！
```

同样的符号，遇到不同类型干不同的事，这就是为什么要先认清类型。

### 4. 类型转换（10 分钟）

既然类型不能乱混，就需要**转换工具**。三个最常用：

```python
# str()：数字 → 文字
str(2026)        # 得到 "2026"

# int()：文字/小数 → 整数
int("2026")      # 得到 2026
int(3.9)         # 得到 3   ← 直接砍掉小数，不四舍五入！

# float()：文字/整数 → 小数
float("3.14")    # 得到 3.14
float(5)         # 得到 5.0
```

把它们用起来，上一课那个报错就解决了：

```python
days = 2
print("今天是我学习的第 " + str(days) + " 天")   # 转成文字才能拼
```

反过来，文字要参与计算，也得转：

```python
age_text = "18"
next_age = int(age_text) + 1
print("明年我 " + str(next_age) + " 岁")
```

**为什么这一步在 Agent 开发里特别重要**：大模型返回的内容**永远是一段文字**。模型说「3」，你拿到的是 `"3"` 不是 `3`，想拿它算数就必须 `int()`。这个坑在实际项目里天天出现。

**转换失败的情况**（记住，别慌）：

```python
int("abc")       # 报 ValueError：不是所有文字都能变数字
int("3.14")      # 也报错！小数文字要用 float("3.14")
```

`ValueError` 的意思是「值不对」。它和 `SyntaxError`（句子写错）、`NameError`（名字不认识）、`TypeError`（类型不匹配）是四种不同的报错，**看报错名就能定位方向**。

### 第 4 题 · 25 分 · 得 0 分

**题目**：执行 `value = int("3.14")` 这一行，会得到什么结果？

- A. `value` 是 `3`，小数部分被砍掉
- B. `value` 是 `3.14`
- C. 报 `ValueError`，`"3.14"` 不能用 `int()` 转
- D. `value` 是字符串 `"3"`

**你的回答**：A

**正确答案**：**C**（报 `ValueError`）

**评语**：这是今天唯一的错，而且是个很容易踩的坑——你把 `int(3.9)` 的行为套到了 `int("3.14")` 上。关键区别在于**括号里是数字还是文字**：

| 表达式 | 结果 | 原因 |
| --- | --- | --- |
| `int(3.9)` | `3` | 括号里是**数字**，转整数时砍掉小数 |
| `int("3.14")` | **ValueError** | 括号里是**文字**，`int()` 只认「整数字面量」的文字，`"3.14"` 带小数点，直接被拒 |
| `int("3")` | `3` | 这才是能转的文字 |
| `float("3.14")` | `3.14` | 小数文字要用 `float()` |

一句话记法：**`int()` 砍小数，只对数字有效；对文字，它只接受长成整数的样子（`"3"`），带小数点就报 `ValueError`。**

这条在你以后处理大模型返回值时会天天遇到：模型给的都是文字，你得先判断它是不是带小数点，再决定用 `int()` 还是 `float()`。
