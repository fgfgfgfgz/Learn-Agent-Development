## 今日知识点（25 分钟）

### 1. if 的基本形状：冒号 + 缩进（7 分钟）

```python
score = 87

if score >= 80:
    print("通过")
    print("可以进入下一阶段")
```

三件事必须同时对上，少一个就报错：

| 要素 | 说明 |
| --- | --- |
| `if` 后面跟**条件** | `score >= 80`，结果必须是 `True` 或 `False` |
| 条件末尾加**英文冒号 `:`** | 漏了直接 `SyntaxError` |
| 下一行**缩进 4 个空格** | 多个空格也行，但**同一块必须完全一致** |

**关键理解**：缩进不是「为了好看」，**它是语法本身**。Python 靠缩进判断「哪些行属于这个 if」。别的语言用大括号 `{}`，Python 用空格——这就是为什么它看起来干净，但也更容易因空格出错。

```python
score = 87

if score >= 80:
    print("通过")      # 属于 if，条件成立才执行
print("程序结束")      # 没有缩进，不属于 if，永远执行
```

**这里有个必须分清的点**：`print("程序结束")` **不管条件成不成立都会打印**，因为它没缩进、不在 if 里。这是新手最容易看错的地方——**不看缩进就判断不出哪几行受条件控制**。

### 2. `=` 和 `==` 是两件完全不同的事（4 分钟）

```python
score = 87        # 一个等号：赋值，把 87 装进 score
print(score == 87)  # 两个等号：判断，问「相等吗」，返回 True
print(score == 90)  # False
```

| 写法 | 含义 | 结果 |
| --- | --- | --- |
| `score = 87` | 赋值 | 变量变成 87 |
| `score == 87` | 判断相等 | `True` / `False` |

**这是最经典的新手事故**：在 `if` 里写成 `if score = 87:`，Python 会直接报 `SyntaxError: invalid syntax`（这是好事，立刻发现）。更隐蔽的是 `if score:` —— 它不报错，但意思是「`score` 是不是真值」，跟你想的「等于」完全不是一回事。

六个比较运算符，一次认清：

```python
print(87 == 87)   # True   相等
print(87 != 90)   # True   不相等
print(87 > 80)    # True   大于
print(87 < 80)    # False  小于
print(87 >= 87)   # True   大于或等于
print(87 <= 86)   # False  小于或等于
```

### 3. else 与 elif：两条路、多条路（5 分钟）

**两条路**，用 `else`：

```python
score = 55

if score >= 60:
    print("及格")
else:
    print("不及格")
```

`else` 后面**不跟条件**（它表示「以上都不满足」），但要跟冒号，内容照样缩进 4 格。

**多条路**，用 `elif`：

```python
score = 87

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print(f"等级：{grade}")     # 等级：B
```

**`elif` 最关键的规则：从上往下，命中第一个就停，后面的不再看。** 所以 87 分虽然也满足 `>= 60`，但因为 `>= 80` 已经命中，就停在 B，不会再变成 C。

**由此推出一条实用结论：`elif` 的顺序必须从严格到宽松。** 如果把 `>= 60` 写在最前面，87 分就会直接判成 C——**代码不报错，但逻辑全错**。这类「跑得通但结果错」的 bug，比报错难查得多。

### 4. and / or / not：把条件组合起来（5 分钟）

```python
score = 87
checked = True

if score >= 80 and checked:
    print("可以发证书")

if score >= 95 or checked:
    print("至少满足一条")

if not checked:
    print("还没审核")
else:
    print("已审核")
```

| 运算符 | 含义 | 什么时候为 `True` |
| --- | --- | --- |
| `and` | 并且 | **两边都真**才真 |
| `or` | 或者 | **有一边真**就真 |
| `not` | 取反 | 把真变假、假变真 |

`and` 和 `or` 都是「短路」的：`and` 遇到第一个 `False` 就停下（后面不看），`or` 遇到第一个 `True` 就停下。这在后面写「先检查密钥存在、再发请求」时很有用——密钥没有就不必发请求了。

### 5. 真值：不是只有 True / False 才能当条件（4 分钟）

这是今天最有意思的一点。**任何值放进 if，Python 都会自动判断它是「真」还是「假」**：

```python
todo = []

if todo:
    print("有任务")
else:
    print("清单是空的")     # 会走这里

if not todo:
    print("确认：清单为空")  # 也会打印
```

**被判为「假」的常见值**（记住这几个就够用）：

| 值 | 判断结果 |
| --- | --- |
| `[]` 空列表 | 假 |
| `""` 空字符串 | 假 |
| `0` / `0.0` | 假 |
| `None` | 假 |
| `False` | 假 |
| 非空的列表、非空字符串、非零数字 | **真** |

所以 `if todo:` 的意思是「**清单里有东西吗**」，比 `if len(todo) > 0:` 更简洁，而且一样清楚。**这是 Python 里非常地道的写法**，你在别人的代码里会天天见到。

**但它也有坑**：`if score:` 在 `score = 0` 时判定为假——如果你的业务里「0 分」是合法数据，这么写就错了，得写 `if score is not None:`。今天先知道有这回事。

todo = ["装 Python", "学变量", "学字符串", "学列表", "学 if"]

if not todo:
