## 回顾与补漏（20 分钟）

### 上次那个错，用四行代码讲清

上次你答 `int("3.14")` 会「得 3，砍掉小数」。这个判断错在**把两件不同的事当成了同一件**：

- `int(3.9)` 括号里是**数字**，转整数 = 砍掉小数部分 → `3`
- `int("3.14")` 括号里是**文字**，`int()` 要先"读懂"这段文字，而 `"3.14"` 不是合法的整数写法 → 直接拒绝，报 `ValueError`

**现在动手跑这四行**（新建 `练习/20261114/cast_test.py`）：

```python
print(int(3.9))          # 数字，砍掉小数
print(int("3"))          # 文字，但长得像整数，能转
print(float("3.14"))     # 文字带小数点，要用 float
print(int("3.14"))       # 这一行会报错，故意留着
```

运行 `python cast_test.py`，你会看到前三行正常输出、第四行抛出一条红色报错。**把这条报错读一遍**，你会看到：

```
ValueError: invalid literal for int() with base 10: '3.14'
```

`invalid literal` 直译是「无效的字面量」——意思是「你给我的这段文字，不是我能认的整数写法」。

**把最后一行注释掉再跑一次**，确认前三行都正常。

> 一句话规则：**`int()` 遇到数字砍小数，遇到文字则要求格式合法。带小数点就去找 `float()`。**

### 为什么这件事值得花 20 分钟

不是因为这个知识点本身难，而是它代表了一类思维习惯：**同一个函数，喂给它不同类型的东西，行为会变**。后面调用大模型 API 时你会反复遇到——模型返回的内容永远是字符串，`"3"` 和 `3` 差一个引号，代码就会崩。

## 今日知识点（24 分钟）

### 1. 字符串就是一段文字，长得像列表但不是（4 分钟）

```python
s = "Hello"
print(len(s))      # 5，字符个数
print(s[0])        # H，第一个字符（从 0 开始数！）
print(s[-1])       # o，最后一个字符（负数从末尾数）
```

**索引从 0 开始**，这是编程的通例，不是 Python 特殊。`s[0]` 是第一个，`s[4]` 是最后一个（`Hello` 有 5 个字符，索引 0–4）。

**常见坑**：`s[5]` 会报 `IndexError: string index out of range`——超出范围了。

### 2. 切片：一次取一段（6 分钟）

```python
s = "Hello World"
print(s[0:5])      # Hello    从 0 取到 5，但「含头不含尾」
print(s[6:])       # World    从 6 取到结尾
print(s[:5])       # Hello    从头取到 5
print(s[-5:])      # World    取最后 5 个
```

**核心规则：`[起:止]` 含头不含尾**。`s[0:5]` 取索引 0、1、2、3、4，**不含 5**。这是新手最常错的地方，记住「左闭右开」。

为什么这么设计？因为 `s[0:5]` 的长度就是 `5 - 0 = 5`，算起来省事。习惯就好。

### 3. 常用方法：改名、去空白、替换（6 分钟）

方法就是「字符串自带的功能」，用 `.` 调用：

```python
s = "  Hello World  "

print(s.upper())          # "  HELLO WORLD  "   全大写
print(s.lower())          # "  hello world  "   全小写
print(s.strip())          # "Hello World"       去掉两端空白
print(s.replace("World", "Python"))   # "  Hello Python  "  替换
print(s.split(" "))       # ['', '', 'Hello', 'World', '', '']  按空格切
```

**三个必须知道的点**：

1. **这些方法不改原字符串**。`s.upper()` 只是**返回一个新字符串**，`s` 本身没变。想保存结果必须赋值：`s2 = s.upper()`。这是零基础最容易懵的地方——以为调了方法原值就变了。
2. **`strip()` 最常用**。从文件、网页、用户输入拿到的文字，两头经常带空格或换行，不清理会让比较、拼接全出错。
3. **`split()` 返回的是列表**（用方括号包着的一串值），不是字符串。列表下次正式讲，今天只要看到它的样子不慌就行。

### 4. f-string：拼接的正确姿势（8 分钟）

还记得你之前问的「为什么要 `str(days)`」吗？现在有更省事的写法了：

```python
name = "小明"
days = 3
score = 87.5

# 老写法：又加号又 str()，还容易漏
print("我是" + name + "，学了 " + str(days) + " 天，得分 " + str(score))

# f-string：一个 f 开头，变量直接塞进花括号
print(f"我是{name}，学了 {days} 天，得分 {score}")
```

两行输出完全一样，但第二行**不需要 `+`、不需要 `str()`、不会因为类型不匹配报错**。

规则只有三条：

1. 字符串前面加 `f`（或 `F`）
2. 变量用 `{}` 包起来
3. `{}` 里可以写表达式，不只是变量名：

```python
days = 3
print(f"一周还剩 {7 - days} 天")          # 花括号里能算
print(f"得分率 {score / 100:.1%}")        # 甚至能格式化，这个以后讲
```

**为什么 f-string 是重点**：从今天起，你所有拼接字符串的地方都该用它。写提示词、拼 API 请求、输出日志，全都用得上。**`+` 拼接加 `str()` 那种写法，除非有特殊理由，以后不要再用。**

**常见坑**：忘了写 `f`。`print("{name}")` 会原样输出 `{name}` 四个字符，不报错，但结果不对——这种「不报错但结果错」的 bug 最难查。

**题目**：情境：你在整理价格数据，`price = 19.9` 是一个数字（不是文字）。执行 `print(int(price))` 会输出什么？

- B. `19.9` —— 原样输出，什么都不变
- C. `20` —— 四舍五入到最接近的整数

**你的回答**：**A**（`19`）

**正确答案**：**A**

**评语**：答对，而且这题故意放了 C（四舍五入）和 D（把文字侧的规则套过来）两个典型陷阱。`int()` 喂进去的是**数字**时，只砍小数、不四舍五入。对照记一下：`int(19.9)` → `19`，但 `int("19.9")` → `ValueError`。差一个引号，行为完全不同。

### 第 3 题 · 25 分 · 得 25 分

**题目**：运行下面两行，屏幕上会输出什么？

```python
s = "Agent"
print(s[1:4])
```

- A. `Age` —— 从开头取 3 个字符
- B. `gent` —— 从索引 1 取到 4，含末尾
- C. `gen` —— 从索引 1 取到 4，含头不含尾
- D. `Agen` —— 从开头取到 4，含末尾

**你的回答**：**C**（`gen`）

**正确答案**：**C**

**评语**：切片「含头不含尾」是这节课最容易错的地方，你一次就过了。`"Agent"` 的索引是 `0:A / 1:g / 2:e / 3:n / 4:t`，`[1:4]` 取索引 1、2、3 得到 `gen`，**不含**索引 4 的 `t`。B 就是「把尾巴也算进去」的典型误选，你避开了。
