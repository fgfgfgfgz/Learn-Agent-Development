## 今日知识点（25 分钟）

### 1. 列表是什么（5 分钟）

```python
todo = ["装 Python", "学变量", "学字符串"]
print(todo)          # ['装 Python', '学变量', '学字符串']
print(len(todo))     # 3
```

- 方括号 `[]` 包起来，逗号分隔，里面每一个叫「元素」。
- `len()` 和字符串用的是**同一个函数**，这里数的是元素个数。
- 列表里**能混装不同类型**：`mix = ["小明", 4, True, 3.14]` 完全合法。
- 空列表写作 `[]`。

### 2. 索引和切片：规则和字符串一模一样（5 分钟）

```python
todo = ["装 Python", "学变量", "学字符串"]
print(todo[0])       # 装 Python      从 0 开始
print(todo[-1])      # 学字符串       负数从末尾数
print(todo[0:2])     # ['装 Python', '学变量']    含头不含尾
```

不用重新学——`[0]`、`[-1]`、`[起:止]` 含头不含尾，和 11-14 的字符串规则**完全相同**。这也是为什么先学字符串再学列表。

**坑**：`todo[3]` 只有 3 个元素（索引 0–2），会报 `IndexError: list index out of range`，和字符串越界是同一类错。

### 3. 增、改、查：列表能原地改（8 分钟）

```python
todo = ["装 Python", "学变量"]

todo.append("学字符串")      # 末尾加一个
print(todo)                  # ['装 Python', '学变量', '学字符串']

todo[1] = "学变量（已掌握）"  # 按索引改
print(todo)

print("学字符串" in todo)    # True，判断在不在里面
print(len(todo))             # 3
```

**今天最该记住的一个对照**：

| | 字符串 | 列表 |
| --- | --- | --- |
| 调用方法后 | `s.upper()` 返回新值，**原来的不变** | `todo.append(...)` **直接把原列表改了** |
| 想保留结果 | 必须 `s2 = s.upper()` | 不用赋值，调完就已经变了 |

所以 **`todo = todo.append("x")` 是错的**：`append()` 原地改完列表后返回的是 `None`（空值），这么一赋值反而把列表弄丢了。直接写 `todo.append("x")` 就行。

`in` 返回 `True` / `False`（bool，11-13 见过），后面写条件判断时天天用。

### 4. 字符串 ↔ 列表：split 与 join（7 分钟）

上节课 `split(" ")` 把 `"  Hello World  "` 切出了一堆空字符串，因为按**单个空格**切时，连续空格之间会切出空内容。更实用的写法是**不写参数**：

```python
text = "  Python  让  Agent  开发  变简单  "
words = text.split()        # 不写参数 = 按任意空白切，自动忽略连续空格
print(words)                # ['Python', '让', 'Agent', '开发', '变简单']
print(len(words))           # 5
```

反过来，把列表拼回一个字符串用 `join()`：

```python
print("-".join(words))      # Python-让-Agent-开发-变简单
```

**`join()` 的方向最容易写反**：是「分隔符 `.join(列表)`」，分隔符写在前面去调用；不是 `words.join("-")`。

**为什么这两个是重点**：大模型返回的是一整段文字，你要么先 `split()` 拆成一条条处理，要么把处理好的一堆片段用 `join()` 拼回提示词。这是后面 RAG 和工具调用里最基础的操作。

### 第 1 题 · 12.5 分 · 得 12.5 分

**题目**：运行下面两行，输出什么？

```python
mix = ["小明", 4, True]
print(len(mix))
```

- A. `3` —— 三个元素，列表允许混装不同类型
- B. 报 `TypeError` —— 认为列表里只能放同一种类型
- C. `2` —— 认为 `True` / 数字不算元素
- D. `4` —— 认为要把索引位置也算进去

**你的回答**：**A**（`3`）

**正确答案**：**A**

**评语**：答对。列表**不管元素类型**，`"小明"`、`4`、`True` 各算一个元素，`len()` 数的是元素个数。这里最容易的误区是以为「列表必须同类型」（B）——那是 C 语言数组的直觉，Python 没这个限制。反过来记：正因为能混装，后面从 API 拿到的结构化成对数据（名字 + 分数 + 是否通过）才能直接塞进一个列表。

### 第 3 题 · 12.5 分 · 得 12.5 分

**题目**：运行下面三行，两个 `print` 分别输出什么？

```python
todo = ["装 Python"]
todo2 = todo.append("学变量")
print(todo)
print(todo2)
```

- A. `['装 Python', '学变量']` 和 `None` —— `append` 原地改了 `todo`，但它自己返回 `None`
- B. `['装 Python']` 和 `['装 Python', '学变量']` —— 认为 `append` 返回新列表、原列表不变
- C. 两个都是 `['装 Python', '学变量']` —— 认为两个变量指向同一个列表
- D. 报错 —— 认为把 `append` 结果赋给变量会报错

**你的回答**：**A**

**正确答案**：**A**

**评语**：**这是今天含金量最高的一题，你一次答对。** 它同时考了三层：

1. `append()` **原地修改**原列表 → 所以 `print(todo)` 已经有 `"学变量"`；
2. `append()` 的**返回值是 `None`** → 所以 `print(todo2)` 打印 `None`；
3. 因此 `todo = todo.append("x")` 这种写法会**把列表弄丢**，变成 `None`。

对照昨天刚学的字符串：`s.upper()` 返回新值、原值不变；`todo.append()` 原地改、返回 `None`。**同样带点、同样是方法，行为相反**——你能分清，说明这个对照是真的进脑子了。这也正是今天重点设计这个对照点的目的。

### 第 5 题 · 12.5 分 · 得 12.5 分

**题目**：运行下面两行，输出什么？

```python
todo = ["装 Python", "学变量"]
print("变量" in todo)
```

- A. `False` —— 按完整元素比较，没有这个元素
- B. `True` —— 认为包含子串就算成员
- C. 报 `TypeError` —— 认为类型不同不能判断
- D. 返回 `2` —— 认为 `in` 返回的是位置

**你的回答**：**A**（`False`）

**正确答案**：**A**

**评语**：答对，而且这题专门设了 B 这个陷阱——**`in` 对列表是「整元素相等」，不是「子串包含」**。`"变量"` 只是 `"学变量"` 的一部分，不算成员，所以 `False`。而字符串上的 `"变量" in "学变量"` 会得到 `True`。同一个 `in`，列表比整体、字符串比子串，这又是一处「同一符号在不同类型下行为不同」。

`in` 返回的永远是 `True` / `False`（bool），不是位置——想找位置要用 `.index()`，以后讲。

### 第 6 题 · 12.5 分 · 得 12.5 分

**题目**：运行下面两行，输出什么？

```python
text = "  Python  让  Agent  变简单  "
print(text.split())
```

- A. `['Python', '让', 'Agent', '变简单']` —— 不写参数时按任意空白切、自动忽略连续空格
- B. `['  Python  让  Agent  变简单  ']` —— 以为不传参会把整段当 1 个元素
- C. 含多个空字符串的列表 —— 以为不传参等价于按单个空格切
- D. 报 `TypeError` —— 以为不写参数会报错

**你的回答**：**A**

**正确答案**：**A**

**评语**：答对。**`split()` 带参数和不带参数不是一回事**：

| 写法 | 行为 |
| --- | --- |
| `split(" ")` | 严格按单个空格切，连续空格之间切出**空字符串** `''` |
| `split()` | 按**任意空白**（空格、制表符、换行）切，**自动丢弃**连续空白和首尾空白 |

你昨天练习里那个 `['', '', 'Hello', 'World', '', '']` 就是 `split(" ")` 的结果，今天就给出了更实用的解法。**处理真实文本几乎总是用 `split()`**，因为你无法预知对方用几个空格还是换行分隔。

### 第 7 题 · 12.5 分 · 得 12.5 分

**题目**：运行下面两行，输出什么？

```python
words = ["a", "b", "c"]
print("-".join(words))
```

- A. `'a-b-c'` —— 分隔符排在前面调用 `join`
- B. 报 `AttributeError` —— 把 `join` 的方向写反了
- C. `'a b c'` —— 认为会拼成带空格的一串
- D. `['a', 'b', 'c']` —— 以为 `join` 是列表的方法

**你的回答**：**A**（`'a-b-c'`）

**正确答案**：**A**

**评语**：答对。**`join` 的方向是「分隔符在前」**：`"-".join(words)`，是字符串 `"-"` 去调用 `join`，把列表灌进来。写成 `words.join("-")` 就会报 `AttributeError`（列表没有 `join` 方法）。

记法：**谁在前面，谁就是「粘合剂」**。想做 `"a-b-c"` 就用 `"-"` 当粘合剂；想用换行拼就用 `"\n".join(...)`；什么都不想加就用 `"".join(...)`（空字符串当粘合剂）。
