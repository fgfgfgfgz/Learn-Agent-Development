## 今日知识点（30 分钟）

### 1. 重复的第一印象：`while` 的三要素（9 分钟）

```python
n = 3
while n > 0:
    print(f"倒计时 {n}")
    n = n - 1
print("发射！")
```

输出：

```
倒计时 3
倒计时 2
倒计时 1
发射！
```

三件事缺一不可：

| 要素 | 例子 | 作用 |
| --- | --- | --- |
| 循环条件 | `n > 0` | 为真就重复，为假就跳出 |
| 缩进的循环体 | 两个 `print` 和 `n = n - 1` | 每轮要做的事，缩进 4 格 |
| **改变条件的语句** | `n = n - 1` | 让条件最终变假，**否则永远停不下来** |

**最容易翻车的是第三条。** 去掉 `n = n - 1`，`n` 永远是 3，条件永远为真，程序会无限打印「倒计时 3」——这就是**死循环**。真跑起来只能靠按 `Ctrl + C` 强行停下。写代码时养成习惯：**每写一个 `while`，立刻问自己"它什么时候会停？"**

`while` 和 `if` 长得很像（都是条件 + 冒号 + 缩进），但意思完全不同：`if` 判断一次，`while` 判断很多次。

### 2. `break` 与 `continue`：控制循环的走向（6 分钟）

```python
n = 0
while True:              # True 永远成立，故意造一个无限循环
    n = n + 1
    if n == 3:
        continue         # 跳过本轮剩下的代码，直接下一轮
    if n == 5:
        break            # 直接跳出循环，不再继续
    print(n)
```

输出：

```
1
2
4
```

- `continue`：这一轮不干了，跳到下一轮（3 没打印）
- `break`：整个循环终止（5 和之后都不打印）

`while True:` 配 `break` 是非常常见的写法——「一直等，直到用户说退出」，今天的待办清单就用它。

### 3. `if` 嵌套：判断里再判断（6 分钟）

昨天 `todo_check.py` 里你已经见过嵌套（if 里面又有 if），今天正式认识它：

```python
age = 20
user = "小明"

if age >= 18:
    print("成年")
    if user == "小明":
        print("是小明本人")   # 内层 if，缩进 8 格
else:
    print("未成年")           # 和外层 if 对齐，属于外层
```

输出：`成年` / `是小明本人`

**关键只看缩进**：内层 `if` 比外层多缩进 4 格，所以它「挂在外层里面」——只有外层条件成立，才会走到内层。而 `else` 和外层 `if` 对齐，所以属于外层。

判断顺序：先看最外层 → 成立了才看里面那层 → 里面不成立就什么都不做（不会掉到外层的 `else` 去）。

### 4. `input()`：让程序听你说话（9 分钟）

前面所有程序的数据都是写死的。`input()` 让程序能**在运行时问你**：

```python
name = input("你叫什么名字？")
print(f"你好，{name}")
print(type(name))        # <class 'str'>
```

运行后程序会停在那等你输入，敲回车才继续。`input()` **永远返回字符串**——这是它最大的坑：

```python
age = input("你几岁？")
# print(age + 1)          # 报错！字符串不能加数字
age = int(input("你几岁？"))  # 转成整数才行
print(age + 1)
```

- 想当数字用：`int(input(...))`，想带小数用 `float(input(...))`
- 只是比较、打印，不运算：直接用字符串没问题（今天的菜单选择就是）

转换失败的坑先知道：`int("abc")` 会报 `ValueError`——这正是 11-13 你学过的转换边界，今天原样复用。

## 动手练习（20 分钟）

产出：`练习/20261117/todo_cli.py`

把 11-16 的 `todo_check.py` 升级成**能反复操作的命令行待办清单**：

```python
todo = ["装 Python", "学变量", "学 if"]

while True:
    print("\n===== 待办清单 =====")
    print("1. 查看清单")
    print("2. 添加任务")
    print("3. 检查某项")
    print("4. 退出")

    choice = input("请选择 1-4：")

    if choice == "1":
        i = 0
        while i < len(todo):
            print(f"{i + 1}. {todo[i]}")
            i = i + 1
    elif choice == "2":
        new = input("输入新任务：")
        todo.append(new)
        print(f"已添加「{new}」")
    elif choice == "3":
        target = input("要检查哪项：")
        if target in todo:
            print(f"「{target}」在清单里")
        else:
            print(f"「{target}」不在清单里")
    elif choice == "4":
        print("再见！")
        break
    else:
        print("输入有误，请输入 1-4")
```

**跑起来做这四件事**（每一步都亲眼看到结果）：

1. 选 `1` → 看到 3 项任务（这里用 `while` 遍历列表，因为 `for` 还没学）
2. 选 `2` 添加「学循环」→ 再选 `1`，确认它真出现了（`append` 原地改）
3. 选 `3` 输入「学循环」→ 在清单里；再输「学函数」→ 不在清单里（**整元素比较**）
4. 选 `4` → 程序打印「再见！」并退出（`break` 生效）

**再故意试一次**：选 `9`，看它走 `else` 提示输入有误——这就是默认分支的用途。

**第 7 题**（新知 · 菜单里字符串比较）　得分 **0** ❌
- 题目：菜单写 `if choice == "1":`，choice = input(...)。为什么不写 `if choice == 1:`？
- 选项：A. 写 1 会直接报错｜B. input 返回字符串，写 1 永远不成立｜C. 两种写法效果一样｜D. 菜单只能输入文字
