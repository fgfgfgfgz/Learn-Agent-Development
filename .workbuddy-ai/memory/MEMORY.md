# 项目长期笔记 · 学习计划工作区

## 项目目标

为零基础用户制定「AI Agent 应用开发」一年学习计划：每天约 1 小时，起始 2026-11-11。终点是**转行求职 AI Agent 开发**（2 个可展示项目 + 简历段落 + 面试准备）。

## 用户已确认的约定

- 技术路线：**代码为主**（Python → 大模型 API → 手搓 Agent → RAG → LangGraph → 工程化），Dify/Coze 仅作体感辅助。
- **不要创建定时自动推送/自动化任务**。用户每天主动来说「今天学什么」，由我即时生成当日学习卡。
- 要求每天给出**具体知识点与可执行的练习**，不能只推荐书单或学习方向。
- **新函数/新内置对象/新方法必须用统一「函数卡片」讲清**（2026-11-19 用户建议）：① 它是什么（一句话+比喻）② 参数（逐个列、标必填/可选及默认值、说明每个含义）③ **返回值是什么类型（必写，含返回 None 的情况）** ④ 最小可运行例子带 print 输出 ⑤ 常见坑/边界。适用于 `range()`、`len()`、`input()`、字符串/列表方法、`open()`、requests、框架 API 等一切新函数。宁可多花 3 分钟讲透，不要让用户"会用但说不清"。
- 要求每日检测，并**依据成绩调整下次内容**。
- **命名一律用 8 位实际日期**：`每日学习卡/YYYYMMDD.md`、`练习/YYYYMMDD/`。
- **任何地方都不要课次编号**（不说「第 4 课」「第 004 课」，不写进文件名、标题、档案、对话），一律用日期指代。2026-11-13 用户明确要求后已全系统去编号。
- **学习卡与对话讲解里不得出现任何检测题目/题型/答案/考点配比清单**。用户学完发口令「今天内容学完了，请对我的学习情况进行检查」后，我再用交互式提问卡片**现场出题**。
- **检测题量（2026-11-14 用户要求「题太少、重点放新知识」）：每次 8 题 × 12.5 分**，其中 **6 题考当天新知识 + 2 题回顾/复测**（A 档 7+1）；卡片一次最多 4 题，**分 2 批呈现**。得分按答对题数换算（8→100 / 7→87.5 / 6→75 / 5→62.5 / 4→50），档位分数线不变。8 题全部为纯选择题（可含「读代码判断输出」）。
- **检测后必须把 8 道题的原文、选项、用户作答、正确答案、得分、评语完整回填到当日学习卡的「批改记录」**（含汇总表，8 题全写）。「学习阶段不透露题目」不等于「检测后不记录题目」。
- **需要贴代码/运行输出/写文字的题，一律不进提问卡片、不占 8 题名额、不计分**，改为在回复正文里直接问、自愿提交（卡片里选项与自由输入互斥，用户曾两次因此无法作答被扣冤枉分）。题干必须完整可读。
- **出题方式补充（2026-11-18）**：题干不加提示性描述（半揭答案、测不出真实掌握）；考不出就作废、不赖用户。
- **出题方式硬约束（2026-11-16 用户当场指出）**：提问卡片里放多行缩进代码会被挤成一行、缩进完全看不到。凡涉及缩进的读代码题，一律用 `␣␣␣␣` 显式标注 4 格空格，或改为文字描述「哪行缩进、哪行不缩进」，**不得把多行缩进代码原样塞进卡片**。若因排版缺陷致用户看不清，按规则正常计分但记为出题方式问题。
- **某天没学 = 整体顺延**：不生成卡、内容不往前推进、不补作业、不压缩补课；总量不变，结束日期后移。
- **会话被误删的处理（2026-11-18 首次发生）**：用户要求从工程目录恢复会话。工程目录里的档案/学习卡/练习/memory 日志就是完整状态源，按顺序读 `进度档案.md` → 总览第二节 → 最近 1–2 份学习卡 + memory 日志即可无损恢复，不需用户重述任何背景。

## 文件与状态源

- `学习计划总览.md`：12 个月路线、评分规则、调整规则、顺延规则、**AI 执行协议**（新会话必读）。
- `进度档案.md`：**唯一状态源**。上次学到哪、成绩、薄弱点、下次调整指令都在这里。
- `每日学习卡/YYYYMMDD.md`：当日内容（**不含检测题**）+ 检测后回填的完整批改记录。
- `练习/YYYYMMDD/`：用户代码。

## 每次新会话必须遵守

1. 先读 `进度档案.md` 与 `学习计划总览.md` 第二节，再读按日期排序的最近 1–2 份学习卡。
2. 「下次调整指令」优先级高于月度大纲。
3. 用户说「今天学什么」：生成 `YYYYMMDD.md` 并在对话里把内容讲出来，**绝不出题、绝不透露会考什么**，讲完就停。全程不出现课次编号。
4. 用户发检查口令：现场出 8 题（6 题新知 + 2 题回顾，A 档 7+1；分 2 批卡片，每题 12.5 分）→ 收答案 → 逐题批改 → 更新档案 → 把 8 题原文、选项、作答、答案、评语、汇总表完整回填当日学习卡。需贴文本的题走正文、不计分。
5. 用户说没学/请假：只顺延，不生成卡、内容不往前推进。
6. C 档（<60）重学日内容不往前推进。
7. 零基础语气：一次讲透一件事，每个知识点配可运行示例，禁止「去看某书第 X 章」式内容。
